# GroundTruth Roadmap

GroundTruth is moving from a broad hackathon marketplace to a focused field-evidence product. The first commercial workflow is retail availability, price, promotion, and display verification in a deliberately small launch region.

## Phase 0 — Credibility reset

- [x] Position the product around verified retail field evidence
- [x] Remove synthetic worldwide live-activity presentation
- [x] Label demo and testnet metrics honestly
- [x] Add deployment version metadata at `/api/version`
- [x] Add optional target coordinates and an allowed capture radius
- [x] Capture a worker's browser-reported location and hard-fail out-of-radius submissions
- [ ] Select the first launch city from customer demand and operator availability
- [ ] Separate production, staging, and demo datasets
- [ ] Reconcile and publish the definitive X Layer network and contract configuration
- [ ] Configure a production contact URL and first-party domain

## Phase 1 — Paid retail pilots

- [x] Campaign schema: customer, stores, SKUs, questions, and location-bound requirements
- [x] CSV upload for store lists and campaign results export
- [x] Multi-photo capture with required structured observations
- [x] Expiring evidence links and shareable verification receipts
- [x] Buyer campaign dashboard with exception visibility
- [ ] Webhooks, idempotency keys, and spend caps
- [ ] Worker identity, service radius, availability, and notification preferences
- [x] Public trust surface covering acceptable use, privacy, verification limits, and disputes
- [ ] Recruit a vetted operator cohort in one dense region
- [ ] Complete three paid design-partner campaigns

## Phase 2 — Density and reliability

- [ ] Route-aware task bundles for multiple stores per trip
- [ ] Dynamic pricing based on distance, deadline, and evidence complexity
- [ ] Capture-session and device-risk signals
- [ ] Manual verification fallback with measurable review SLA
- [ ] Buyer and worker reputation models
- [ ] Fiat payout option alongside stablecoin settlement
- [ ] Public completion, dispute, fraud-loss, and turnaround methodology

## Phase 3 — Evidence network

- [ ] Recurring campaigns and scheduled checks
- [ ] Aggregated retail intelligence products with privacy controls
- [ ] Additional evidence types such as video and signed acknowledgements
- [ ] Multi-operator quorum for high-value observations
- [ ] Expand one adjacent geographic cell at a time after committed demand

## Operating targets before fundraising

- 5–10 paying organizations
- 3,000–5,000 genuine paid tasks
- More than 50% of task volume from repeat customers
- At least 95% verified delivery rate
- Under 5% disputed results
- Positive contribution margin in the launch region

The north-star metric is **repeat paid verified tasks per active geographic cell per week**.
